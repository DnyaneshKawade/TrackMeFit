# Specs

One file per feature, written before the code: `T-xxx-short-name.md`, copied from [`_template.md`](_template.md).

Each acceptance criterion gets a test with the same words in its name, so CI shows the spec is met. When behaviour changes later, update the spec in the same PR.

See [docs/engineering.md](../docs/engineering.md) for how specs fit into the workflow.
